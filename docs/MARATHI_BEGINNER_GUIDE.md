### १. मार्केटप्लेसची मूलभूत रचना व मालक खाते (Owner Account)
CHAKRA मध्ये तुम्ही या मार्केटप्लेसचे **मालक (Owner/Admin)** आहात:
* **एकूण विक्री (Gross Sales):** ग्राहकांनी खरेदी केलेल्या एकूण वस्तूंचे मूल्य.
* **प्लॅटफॉर्म कमिशन (Marketplace Commission):** प्रत्येक यशस्वी विक्रीवर वेबसाईट मालकाला मिळणारा सुरुवातीचा **१०%** हिस्सा.
* **विक्रेत्याचा वाटा (Seller Share):** उत्पादनाच्या किमतीतील उर्वरित **९०%** वाटा, जो थेट विक्रेत्याला (Creator) दिला जातो.
* **महत्त्वाचा नियम:** *कधीही अंदाजित किंवा भविष्यातील महसूल हा प्रत्यक्ष मिळालेले पैसे म्हणून दाखवू नका.* जोपर्यंत पैसे Razorpay कडून कापले जात नाहीत व बँकेत UTR द्वारे जमा होत नाहीत, तोपर्यंत ते फक्त प्रक्रिया सुरू असलेले व्यवहार मानले जातात.

### २. कमिशन रचना (Commission Settings)
CHAKRA मधील कमिशन अत्यंत पारदर्शक आणि लवचिक आहे:
1. **डीफॉल्ट कमिशन (Default Commission):** सुरुवातीला हे **१०%** वर सेट केले आहे.
2. **कॅटेगरीनुसार कमिशन (Category-Specific Commission):**
   * ई-बुक्स आणि पीडीएफ: १०%
   * कथासंग्रह आणि पुस्तके: १०%
   * शैक्षणिक नोट्स: १०%
   * डिझाईन आणि टेम्पलेट्स: १०%
   * ऑनलाइन कोर्सेस: १२% (जास्त सर्व्हर बँडविड्थ लागत असल्यामुळे)
   * हस्तकला आणि फिजिकल उत्पादने: ८% (कच्चा माल आणि कुरिअरचा खर्च लक्षात घेऊन)
3. **ठराविक उत्पादनांसाठी खास दर (Product Override):** एखाद्या महत्त्वाच्या विक्रेत्यासाठी किंवा प्रमोशनल ऑफरसाठी तुम्ही विशिष्ट उत्पादनावर ५% किंवा कोणताही दर निश्चित करू शकता.
4. **ऑर्डर लेव्हल स्नॅपशॉट (Immutable Snapshot):** ग्राहकाने खरेदी करताच त्या क्षणीचे कमिशन डेटाबेसमध्ये कायमस्वरूपी नोंदवले जाते. भविष्यात कमिशन बदलले तरी जुन्या व्यवहारांचे हिशोब अचूक राहतात.

### ३. तुमचे बँक खाते सुरक्षितपणे Razorpay शी जोडणे
**सर्वात महत्त्वाची सुरक्षा खबरदारी:**
* **तुमच्या बँकेचा लॉगिन आयडी, पासवर्ड किंवा यूपीआय पिन कधीही या वेबसाईटवर किंवा कोणाशीही शेअर करू नका.**
* मार्केटप्लेसच्या वेबसाईटवर बँकेचे गुप्त पासवर्ड विचारण्याची कोणतीही सोय नसते व तशी गरजही नसते.
* **पायऱ्या:**
  1. अधिकृत **[dashboard.razorpay.com](https://dashboard.razorpay.com)** वर जा.
  2. डाव्या बाजूला **Settings -> Bank Account** वर क्लिक करा.
  3. तुमच्या व्यवसाय बँक खात्याचा नंबर आणि IFSC कोड टाका.
  4. Razorpay आपोआप **Penny Drop** चाचणी करेल (तुमच्या खात्यात ₹१ जमा करून खातेदाराचे नाव आणि पॅन कार्ड पडताळून पाहील).
  5. पडताळणी पूर्ण झाल्यावर दररोज किंवा T+1 / T+2 दिवसांनी सर्व कमिशन थेट तुमच्या खात्यात **RBI UTR नंबरसह** जमा होईल.

### ४. Razorpay Test Mode आणि Live Mode कसे सेट करायचे?
सुरक्षेसाठी Razorpay चे API सीक्रेट्स फक्त **Netlify Environment Variables** मध्ये साठवले जातात:
* **Test Mode (चाचणीसाठी):**
  * Key ID: `rzp_test_...`
  * Key Secret: `...`
  * यामध्ये खऱ्या पैशांशिवाय बनावट कार्ड किंवा UPI द्वारे खरेदी तपासता येते.
* **Live Mode (खऱ्या पैशांसाठी):**
  * Key ID: `rzp_live_...`
  * Key Secret: `...`
  * **महत्त्वाचा नियम:** *लाईव्ह मोडमध्ये कधीही खोटा किंवा बनावट व्यवहार 'यशस्वी' म्हणून दाखवला जात नाही.* जर लाईव्ह पेमेंट अयशस्वी झाले, तर ग्राहकाला स्पष्ट त्रुटी दाखवली जाते.

### ५. Razorpay Route (मार्केटप्लेस स्प्लिट पेमेंट्स)
* **Route म्हणजे काय?**
  * Route द्वारे ग्राहकाने भरलेल्या ₹१,००० मधून ₹१०० मार्केटप्लेसच्या खात्यात राहतात आणि ₹९०० आपोआप विक्रेत्याच्या **Linked Account** मध्ये ट्रान्सफर होतात.
* **महत्त्वाची अट:**
  * साधारण Razorpay खात्यात Route सुविधा लगेच चालू नसते.
  * तुमच्या Razorpay डॅशबोर्डमध्ये **Route** पर्यायासाठी अर्ज करा. Razorpay चे अधिकारी तुमच्या कागदपत्रांची तपासणी करून Route ॲक्टिव्हेट करतील.
  * Route ॲक्टिव्हेट झाल्यावरच Netlify मध्ये `RAZORPAY_ROUTE_ENABLED="true"` करा.

### ६. पर्यायी मॅन्युअल पेआउट पद्धत (Alternative Workflow)
जर तुमचे Razorpay Route अद्याप मंजूर झाले नसेल, तरी घाबरण्याचे कारण नाही:
1. सर्व ग्राहकांचे पैसे सुरक्षितपणे मुख्य मार्केटप्लेस खात्यात जमा होतात.
2. मालकाचे १०% कमिशन मार्केटप्लेसमध्ये वेगळे राहते.
3. **Seller Payouts** डॅशबोर्डमध्ये विक्रेत्याच्या नावापुढे त्याचा बँक खाते नंबर, IFSC किंवा UPI आयडी दिसतो.
4. **"Export Payouts CSV"** बटण दाबून तुम्ही फाईल डाऊनलोड करू शकता आणि तुमच्या नेटबँकिंगमधून (NEFT/RTGS/IMPS किंवा बल्क UPI) विक्रेत्यांना थेट ९०% रक्कम पाठवू शकता.

### ७. Supabase डेटाबेस तयार करणे व नवीन मायग्रेशन्स
1. **[supabase.com](https://supabase.com)** वर जाऊन मोफत प्रकल्प तयार करा.
2. डाव्या बाजूच्या **SQL Editor** वर क्लिक करा.
3. तुमच्या प्रकल्पातील `/supabase/migrations/20260101_commission_payouts_route.sql` ही फाईल उघडा.
4. त्यातील सर्व कोड कॉपी करून SQL Editor मध्ये पेस्ट करा आणि **Run** दाबा.
5. यामुळे खालील ८ अत्यंत सुरक्षित टेबल्स तयार होतील:
   * `commission_rules` (कमिशन नियम)
   * `payment_transactions` (पेमेंट व्यवहार)
   * `order_commissions` (कमिशन स्नॅपशॉट्स)
   * `seller_payouts` (विक्रेत्यांचे पेआउट्स)
   * `affiliate_commissions` (अॅफिलिएट कमिशन)
   * `refunds` (परतावा हिशोब)
   * `settlement_records` (बँक सेटलमेंट नोंदी)
   * `audit_logs` (सुरक्षा ऑडिट नोंदी)

### ८. Netlify वर मोफत वेबसाईट व फंक्शन्स डिप्लॉय करणे
1. कोड **GitHub** वर अपलोड करा:
   ```bash
   git add .
   git commit -m "CHAKRA Marketplace with Owner Commission & Route"
   git push origin main
   ```
2. **[netlify.com](https://netlify.com)** वर लॉगिन करा आणि **"Add new site" -> "Import from Git"** निवडा.
3. **Site configuration -> Environment variables** मध्ये खालील व्हेरिएबल्स जोडा:
   * `NEXT_PUBLIC_SUPABASE_URL` = `https://तुमचा-id.supabase.co`
   * `NEXT_PUBLIC_SUPABASE_ANON_KEY` = `तुमची-anon-key`
   * `SUPABASE_SERVICE_ROLE_KEY` = `तुमची-service-role-key`
   * `RAZORPAY_KEY_ID` = `rzp_test_...` (किंवा live key)
   * `RAZORPAY_KEY_SECRET` = `तुमचा-secret-key`
   * `RAZORPAY_WEBHOOK_SECRET` = `तुमचा-webhook-secret`
   * `RAZORPAY_ROUTE_ENABLED` = `false` (Route मंजूर झाल्यावर `true` करा)
4. **Deploy Site** दाबा. Netlify तुमचे Next.js ॲप आणि सर्व्हरलेस फंक्शन्स स्वयंचलितपणे इंटरनेटवर मोफत लाईव्ह करेल!
